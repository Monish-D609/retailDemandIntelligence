# Raw Data

This project uses the Olist Brazilian E-Commerce Public Dataset.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

To reproduce:
1. Download the dataset zip from the link above (requires free Kaggle account).
2. Extract all 9 CSVs into this folder (`data/raw/`).
3. Run `source("R/data_ingest.R")` from the project root to validate and load them.
